# Definition of Ready (DoR) y Definition of Done (DoD)

Una historia solo entra a desarrollo cuando está preparada y solo termina cuando está realmente validada.

## DoR — gate de entrada a desarrollo
- [ ] Historia definida (`historia_definida`)
- [ ] Reglas de negocio (`reglas_de_negocio`)
- [ ] Criterios de aceptación (`criterios_de_aceptacion`)
- [ ] Flujo aprobado (`flujo_aprobado`)
- [ ] Mockup validado (`mockup_validado`)
- [ ] Dependencias identificadas (`dependencias_identificadas`)
- [ ] Tamaño estimado (`tamano_estimado`)

## DoD — gate de salida a release o cierre
- [ ] Aceptación completa (`aceptacion_completa`)
- [ ] PR revisado (`pr_revisado`)
- [ ] Pruebas OK (`pruebas_ok`)
- [ ] Seguridad validada (`seguridad_validada`)
- [ ] Responsive verificado (`responsive_verificado`)
- [ ] UAT completado (`uat_completado`)
- [ ] Documentación al día (`documentacion_al_dia`)

Marcar con: `python sai.py dor <ID> <item...>` / `python sai.py dod <ID> <item...>`
(G1, G2, G3, G4 y G5 marcan automáticamente los ítems que cubren.)
